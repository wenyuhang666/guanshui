# 算命 App UI 设计大纲（水墨 · 罗盘）

> 2026-11-13 v1。关键词：**水墨、罗盘、留白、内涵、克制**。本文档定方向，具体像素级规范（间距/字号/动效时长）在 v1 开发时固化为 03-设计规范.md。

## 一、设计哲学：一句话

**「一纸、一墨、一印。」** 整个 App 就是一张摊开的宣纸，排盘是研墨落笔，结果页盖一方朱砂印。除此之外的一切装饰都是杂质。

三条铁律：

1. **留白即内容** —— 每屏只说一件事，空白面积 ≥ 50%。信息密度低不是浪费，是"气"。
2. **墨分五色，色不过三** —— 全局只有：宣纸白、墨黑、朱砂红。强调时用金（微金渐变），其余颜色一律不进。
3. **动效像水墨，不像弹窗** —— 所有出现/消失都是"晕染"（opacity + blur + scale 起伏），没有生硬的 slide/弹跳。

## 二、色彩体系

| 角色 | 色值 | 用途 |
|---|---|---|
| 宣纸底 | `#F5F1E6` | 全局背景（叠极淡纸纹噪点） |
| 深宣纸 | `#EBE5D5` | 卡片/分区底色 |
| 浓墨 | `#1C1A17` | 标题、正文主色 |
| 淡墨 | `#8C8577` | 次要文字、说明 |
| 朱砂 | `#A6352C` | 印章、重点断语、CTA 按钮（唯一强调色） |
| 暗金 | `#9A7B3F` | 极少量点缀（罗盘刻度、分隔线） |

暗色模式（可选，v2）：**墨夜** —— 底 `#141311`，字 `#DDD6C4`，朱砂和金不变。像在夜里点灯看盘。

## 三、字体

| 用途 | 字体 | 备注 |
|---|---|---|
| 标题 / 卦名 / 大字 | Ma Shan Zheng（马善政毛笔楷） | Google Fonts 有 webfont，加载失败降级 STKaiti/KaiTi |
| 正文 / 数据 | Noto Serif SC（思源宋体） | 衬线才有"书卷气"，禁用无衬线黑体 |
| 数字排盘 | 同正文宋体，等宽处理 | 干支对齐靠 CSS，不用等宽字体 |

英文/数字极少出现（只有公历日期），同样用衬线体渲染，保持整页气质统一。

## 四、首页：罗盘 Hub（核心创意）

首页 = **一方缓慢自转的八卦罗盘**，是整个 App 的门面和导航：

- 罗盘三层结构（由外向内）：
  - 外环：二十四山向刻度 + 微金细线，极缓慢顺时针自转（120s/圈，若隐若现）
  - 中环：八卦符号 ☰☱☲☳☴☵☶☷，随手指拖拽可拨动（带惯性，拨动时陀螺音效可选）
  - 内盘：中心一枚 **朱砂太极印**，即主按钮
- 三个功能入口不是"菜单"，而是**浮在罗盘上的签牌**：竖排文字小木牌（八字合婚 / 六爻问事 / 今日运势），错落挂在罗盘外缘不同角度
- 点击签牌 → 罗盘加速旋转一圈（0.8s）→ 画面如宣纸浸墨般晕开进入功能页
- 底部一行小字：「玄机参半，人事居中 · 仅供娱乐」—— 免责即气质

设计参照：你确认过的 ai-diag v3「中心轨道架构」（hub + 环绕节点 + 面板从节点生长），这里换成罗盘语境：hub=太极印，环绕=签牌，展开=墨晕。

## 五、功能页布局

### 5.1 八字排盘页

- 上半屏：**竖排四柱**。年月日时四根竖排「墨柱」，干支两字一柱，从右到左读，配五行小色点（仍用墨色深浅区分，不引入蓝绿橙）
- 中部：五行分布用**五枚印章**横陈（金木水火土各一方小印，印文是五行字，浓度代表旺衰）
- 下半屏：解读区，古籍引用统一格式——
  > 「甲木参天，脱胎要火。」——《滴天髓》
  引文用淡墨小字 + 出处落款（像书画题跋），绝不用引用框线
- 大运流年收进可展开的「卷轴」：点击后上下展开，滚动区域两端有卷轴轴头造型

### 5.2 六爻问事页

- 先「净手焚香」仪式感页：用户心中默念所问之事 → **摇卦**：三枚铜钱落下（CSS 3D 翻转，落定带轻微碰撞音效），重复六次成卦
- 装卦结果：**卦象竖排大墨字**（卦名如「泽火革」），六爻从上到下用横线绘制（阳爻墨线、阴爻留白两段），动爻标朱砂点
- 解读：本卦辞 + 变爻爻辞 + 梅花体用断法，均带出处落款

### 5.3 每日运势页

- 竖排「今日签」：一支签浮于画面中央，点击抽出，签文七言竖排显示
- 今日干支、宜忌、吉神方位用**老黄历格**呈现：竖线分隔的小格阵，字竖排，像一页真的黄历

## 六、组件与元素库

| 元素 | 规范 |
|---|---|
| 印章 | CSS 绘制：圆角方、朱砂底白字、微旋转（-6°~6° 随机）、印文用篆意字体（可降级楷体），按压时 scale 0.92 + 印泥加深 |
| 卦象 | Unicode ☰☱☲☳☴☵☶☷ 直接用，墨色渲染 |
| 宣纸纹理 | SVG feTurbulence 噪点叠加，透明度 ≤ 4%，绝不用图片贴图 |
| 分隔线 | 手绘感细墨线（1px 不规则透明度）或「一」字长横，不用圆角卡片边框 |
| 按钮 | 无圆角大按钮。主按钮=一方朱砂印；次要=墨字下划墨线 |
| 弹层 | 墨晕展开，四角羽化（radial-gradient mask），不用圆角白卡 |
| 加载态 | 一滴墨在宣纸上晕开（SVG 动画），文案如「研墨中…」「起卦中…」 |

## 七、动效节奏

| 场景 | 动效 | 时长 |
|---|---|---|
| 页面进入 | 墨晕：opacity 0→1 + blur 8px→0 + scale 1.02→1 | 600ms ease-out |
| 罗盘拨动 | 惯性减速 | 依拖拽，2s 内收敛 |
| 摇卦铜钱 | 3D 翻转下落 | 每次 1.2s，六次可连摇 |
| 报告生成 | 印章盖下（scale 1.4→1 + 轻微透明度闪烁模拟压印） | 400ms，全页最后的仪式点 |
| 呼吸感 | 罗盘外环自转 / 太极印极缓呼吸（scale 1↔1.03） | 持续，120s / 4s |

原则：**同一时刻只有一个主动效**，其余全部静止。宁慢勿闹。

## 八、禁忌清单（对照检查用）

- ❌ 圆角卡片 + 阴影 + 蓝紫渐变（消灭一切"现代 SaaS 味"）
- ❌ 超过三种颜色出现（宣纸白/墨黑/朱砂红之外只允许暗金点缀）
- ❌ 无衬线字体做正文
- ❌ 弹跳、抖动、闪光类动效
- ❌ 图标库图标（一切图标用汉字/卦符/印章代替）
- ❌ 信息塞满一屏；每屏主信息不超过 1 个 + 辅助不超过 3 个
- ❌ 生肖财运话术夸大（"必""定"等字眼），免责声明常驻
- ❌ emoji（一枚印章比十个 emoji 有分量）

## 九、落地顺序

1. 首页罗盘（门面，最能定调）→ 2. 六爻摇卦（仪式感最强，容易出彩）→ 3. 八字排盘页 → 4. 每日运势 → 5. 报告页统一印章落款

v1 全部纯前端零依赖（与 ai-diag/web-demo 同套路），开发完成后按本文档逐条验收，再沉淀像素级规范文档。
